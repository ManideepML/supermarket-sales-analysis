# Supermarket Sales Analysis and Prediction

## Project Overview

This project analyzes supermarket sales data and builds a machine learning model to predict sales using customer, product, and transaction information.

## Dataset

Dataset: SuperMarket Analysis Dataset

Columns include:
- Branch
- City
- Customer Type
- Gender
- Product Line
- Quantity
- Payment
- Sales
- Rating

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Jupyter Notebook

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Feature Encoding
6. Machine Learning Model Building
7. Sales Prediction
8. Performance Evaluation

## Machine Learning Model

Random Forest Regressor

Evaluation Metrics:
- MAE
- MSE
- R² Score
